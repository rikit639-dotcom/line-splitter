# line-splitter

JOSM plugin implementing line splitting algorithm with limited points per segment.

## Description
Details: [OSM Wiki](https://wiki.openstreetmap.org/wiki/JOSM/Plugins/LineSplitter)

## Installation

1. Download `line-splitter.jar` from Releases.
2. Copy it to your JOSM plugins folder.
3. Restart JOSM.
4. The tool will appear in the **Mytools** menu as **Line Splitter**.

## Usage

1. Select one or more ways.
2. Go to **Mytools → Line Splitter** or press `Ctrl+Shift+Z`.
3. Configure parameters (Maximum points per segment) and click **OK**.
