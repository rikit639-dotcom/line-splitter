# line-splitter

Плагин для JOSM, реализующий алгоритм разбиения линий на сегменты с ограничением количества точек.

## Описание
Подробное описание: [OSM Wiki](https://wiki.openstreetmap.org/wiki/RU:JOSM/Plugins/LineSplitter)

## Установка

1. Скачайте файл `line-splitter.jar` из раздела Releases.
2. Скопируйте его в папку плагинов JOSM.
3. Перезапустите JOSM.
4. В меню **Мои инструменты** появится пункт **Разбивщик линий**.

## Использование

1. Выделите одну или несколько линий (Way).
2. Перейдите в меню **Мои инструменты → Разбивщик линий** или нажмите `Ctrl+Shift+Z`.
3. Настройте параметры и нажмите **ОК**.
